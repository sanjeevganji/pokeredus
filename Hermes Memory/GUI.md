## Summary
The GUI is built with Tkinter and provides a team builder, Pokémon browser, set editor, matchup analysis, and 3D graph visualization.

## User Preferences
- NO gradient backgrounds — use type-colored badges
- Notification badges for counts (not text labels)
- Side-by-side layouts over stacked
- Lazy loading (+5 on demand) for long lists
- Bigger fonts filling width
- Stat bars: yellow→green gradient for dominance
- Dark-themed scrollbars
- Sprites in headings and list items
