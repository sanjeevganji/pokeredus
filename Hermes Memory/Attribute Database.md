## Summary
The Attribute/Effect system provides generalised, data-driven conditions and modifiers that can be applied to Pokémon, the field, or the battle. It enables dynamic state tracking and intelligent matchup prediction with complex interactions.

### Attribute Types
- **StatModifierAttribute**: Stat stage changes
- **DamageModifierAttribute**: Damage multipliers
- **SpeedModifierAttribute**: Speed multipliers
- **ConditionAttribute**: Status conditions
- **FieldAttribute**: Weather, terrain, hazards
- **EventAttribute**: Trigger-based effects
