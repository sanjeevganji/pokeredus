## Summary
The Intelligence layer provides algorithms that query the Knowledge Graph for decisions. This includes coverage analysis, speed tier ranking, team building, and AI decision-making.

### Key Functions
- **pick_best_move**: Rank attacker's moves vs a defender
- **find_optimal_switch**: Rank bench candidates vs an opponent
- **analyze_game_state**: Composed stay-or-switch decision
- **team_coverage**: Coverage analysis for a team
- **team_weaknesses**: Uncovered threats
